# フルーティーさの物差し(1〜10)

2026-09-20 制定。設計書 `superpowers/specs/2026-09-19-evaluate-expand-keep-design.md` §7 の決定に基づく。

## なぜ1本の物差しが要るか

度数と苦味は**測った値**だが、フルーティーさは**感じ方**で、測定値が存在しない。
利用者がアップロードしたビールはモデルに推定させるしかない(未登録なら特に)。
だとすれば、**比べる相手の200銘柄も同じ物差しで測る**必要がある。
片方が人手の4段階、もう片方がモデルの推定では、**物差しの違うものを比べる**ことになる。

**この文書が、その1本の物差しである。** 200銘柄の採点にも、
アップロードされた1本の推定にも、**同じ定義を使う**こと。

## 目盛り

| 点 | 状態 | 例 |
|---|---|---|
| **1** | 果実感は無い。意図もされていない | ドライスタウト、シュヴァルツ、ミュンヘナーヘレス、クラシックなピルスナー |
| **2** | ほぼ無い。麦芽・焙煎・ホップの苦味が主役 | ポーター、ボック、アンバーラガー、イングリッシュビター |
| **3** | わずかにある。言われれば気づく程度 | ペールエール、ESB、ケルシュ、ブラウンエール |
| **4** | 控えめにある。香りの一部として感じる | アメリカンペールエール、セゾン(穏やかなもの)、ベルジャンブロンド |
| **5** | はっきり感じる。ただし主役ではない | アメリカンIPA(柑橘系ホップ)、ヴァイツェン(バナナ・クローブ) |
| **6** | 強く感じる。ビールの性格の一部 | トロピカル寄りのIPA、ベルジャンストロング、フルーツを少量使ったもの |
| **7** | 主役のひとつ。果実の名前が説明に出る | ヘイジーIPA、ニューイングランドIPA、フルーツを使ったサワー |
| **8** | 明確に主役。果汁感・ジューシーさが前面 | ジューシー系ヘイジー、果実を多く使ったサワー・ゴーゼ |
| **9** | 果実が中心。ビールより果物が先に来る | 果汁を大量に使ったスムージーサワー、フルーツランビック |
| **10** | 極端。果物そのものに近い | 果肉を大量投入したペストリーサワー、濃縮果汁ベースのもの |

## 判断の順序

1. **紹介文(`ProductExplain`)に書かれていることを最優先する。**
   果実の名前・「ジューシー」「トロピカル」「柑橘」「甘酸っぱい」などの語があれば、それが根拠になる
2. 紹介文に手がかりが無ければ、**スタイル名(`StyleName` / `FamilyName`)の典型値**を使う
3. **どちらも無ければ 3**(判断材料が無いときの既定値)。高くも低くも振らない

## やってはいけないこと

- **甘さとフルーティーさを混同しない。** 麦芽の甘み・カラメル・蜂蜜は果実感ではない
- **アルコールの強さに引きずられない。** 度数は別の軸で扱っている
- **「うまい」「人気」といった評価語に反応しない。** 測るのは果実感だけ
- **全体を無難な中央に寄せない。** 1 や 9 が妥当なら、そう付ける。
  平均に寄せると軸として死ぬ(**それが付け直しの理由そのものである**)

## 記録の規律

- モデルが付けた値は**推定**である。`products.estimated_fields` に `Fruity` を含めること
- 詳細ページでは「※スタイルからの推定値」の補記が出る(既存の仕組み)
