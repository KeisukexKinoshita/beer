## なぜ付け直したか

旧 `Fruity` は1〜4の4段階で、200銘柄の平均が 2.1、**98銘柄が同じ「2」**に入っていた。
評価(③)にも絞り込み(⑤)にも使えない、**軸として死んだ状態**だった。

度数と苦味は測った値だが、フルーティーさは感じ方で測定値が存在しない。
アップロードされたビールはモデルに推定させるしかない以上、
**比べる相手の200銘柄も同じ物差しで測る**必要がある。それが `docs/fruity-rubric.md`。

## 検査したこと(監査)

- 200件の過不足・ID重複・範囲外(1〜10の整数)— **いずれもゼロ**
- **果実語との突き合わせ**: 紹介文に果実の語が無いのに7点以上のもの、
  果実の語があるのに2点以下のものを機械的に洗い出した(4件)。
  すべて紹介文に当たり直し、妥当と確認した:
  - `pr0019` Triple Hazy IPA — 紹介文に味の記述が無く、スタイルの典型値で7
  - `pr0045` Stout / `pr0060` エスプレッソスタウト — 紹介文が**果実感を明示的に否定**している
  - `pr0161` 赤ビール — 「酸味」はあるが果実ではない
- **スタイル別の平均の並び**: Irish Dry Stout 1.0 → American Stout 1.5 →
  … → Hazy IPA 7.3 → New England IPA 8.0 → Radler 9.0。順序に不自然さは無い
- **無作為8件**を紹介文と読み合わせ、点と根拠が一致することを確認
- 10点は0件。該当するもの(果肉を大量に使ったペストリーサワー等)が200銘柄に無いため、
  **無理に付けていない**
