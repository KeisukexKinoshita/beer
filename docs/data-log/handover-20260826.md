## この案件で判明した、パイプラインの欠陥と対処

すべて `/workspace/.claude/skills/beer-data-pipeline` に反映済み。

### 1. writer の隔離が facts の粒度で迂回されていた (round1)

執筆役から Web 取得手段を外して「原文に触れる経路を物理的に断つ」設計だったが、
**収集役の事実カードが出典の言い回しを散文で運んでいた**ため、執筆役は原文を見ないまま
原文の表現を再生産していた。監査役5体が独立に同じ結論に到達。

→ `discipline.md` §5-1: 外観・香りは**順不同の語のリスト**で記録。`stated_in_source` を
   項目ごとの真偽にし、出典に記載が無い項目をスタイル名から補うことを禁止。

### 2. 語リストは語彙を制約するが順序を制約しない (round2)

出典の列挙順がカードに保存され、執筆役がその順序を再生産した。

→ `discipline.md` §5-1: **語の配列は保存時に機械的に並べ替える**。
   規律の文言ではなく生成手順で塞ぐ。

### 3. `appearance` を塞いでも `style_hint` / `notes` が開いていた (round2)

出典の一文がカギ括弧付きで `style_hint` にまるごと入っていた。

→ `discipline.md` §5-1: 自由記述フィールドにも同じ規律。`style_hint` はスタイル名の語だけ。

### 4. 素材が薄いと、構成のなぞりと字数埋めが起きる (round2)

受賞歴・命名由来・製法を拾う枠が無く、執筆役は出典の2文を並べ替えるか
スタイル一般論で埋めるしかなかった。

→ `templates/beer-scout.md`: **`background`** の枠を新設。実際に効き、
   「事実に反する締め」や「販売時期の創作」が構造的に不要になった。

### 5. 創作は締めた場所から隣へ移動する (round2)

外観の断定を潰したら、容器・通年・販売終了時期という第1文と最終文へ移った。

→ `writing-rules.md`: 容器・販売形態・販売時期の禁止を追加。

### 6. その他

- `fields.yaml` の `IBU_all` レンジが既存38銘柄の実測 min/max のままで、
  スタイルとして正しい公式値(IBU 8 / 90)を弾いていた → `[0, 120]` に校正
- `fields.yaml` の `IBU_Style` が `string` 宣言。実カラムは `decimal(6,3)` →訂正
- `make_sql.py` の自己検査がコメントを見ておらず、名前の改行や本文の `;` で
  壊れた SQL を書き出しうる → **runner と同じ読み方で読み直す検査**を追加
- `assets/js/beerglass.js` の正規化値が 0〜1 の外に出うる → 丸めを追加

## 運用上の注意

- **`dev.beer.local` は実在しないホスト名**。ブラウザからは届かない(トンネル + Host ヘッダ専用)。
  ユーザーに案内する URL は ALB のホスト名を使う
- **dev の一時公開経路が開いたまま**。`beer-dev-public.conf`(ALBのホスト名で beer-dev へ、GET/HEAD のみ)。
  当初「ディスカッション終了後に削除する」前提で開けたもの
- **dev と prod に差分**: `001_seed_20260826.sql`(StyleExplain 3件)が dev のみ適用済み
- **ID は再利用しない**。落ちた候補の ID を新候補に使い回したところ、監査記録が別の銘柄を
  指す状態になり、監査役3体が独立に検出した。欠番のまま送る
- **日本の住所のジオコーディングは国土地理院API が最良**
  (`https://msearch.gsi.go.jp/address-search/AddressSearch?q=<住所>`)。
  geocoding.jp / Nominatim では代表点しか返らない、または解決しない例が複数あった。
  なお **WebFetch 経由だと要約が挟まって値が揺れる**ので、`curl` で生の JSON を取ること

## ユーザーの判断で確定済みの事項

- **サンクトガーレンは除外**(robots.txt が GPTBot 等を全面拒否しており、運営者が
  自動収集を望まない意思を明示しているため)
- **新スタイルは新設しない**。全銘柄を既存97スタイルに収める
- **推定の根拠に「出典の定性記述の尺度化」を認める**(色・濁り・果実感を醸造所が
  数値公開することはまず無いため)
