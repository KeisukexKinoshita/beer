# AdSense 審査に向けた準備状況 (2026-08-30)

Google AdSense の審査を通すために何が要り、いま何が済んでいて、何が残っているか。

## このサイト固有の最大の論点 —— アルコールは「制限付きコンテンツ」

**禁止ではない。** [Google パブリッシャー制限](https://support.google.com/adsense/answer/10437795?hl=ja)
が制限対象としているのは次の2つで、該当すると
「有効な広告ソースが減少し、場合によっては広告枠への入札がまったく発生せず、
広告が表示されなくなることもあります」と明記されている。

| 制限対象 | 対応 |
|---|---|
| **アルコール飲料のオンライン販売を促進するコンテンツ** | seed 013 で対応済み。UCHU 30銘柄の「公式サイト」欄がカート付き通販サイトを直接指していたのを、ブランドの公式トップに差し替えた。外部リンクには `rel="nofollow"` を付けた |
| アルコールの無責任な消費を助長するコンテンツ | 該当なし。飲み比べ競争・一気飲みを勧める記述は執筆規律の段階で禁じており、監査でも確認している |

**出典リンク (`source_url`) は通販サイトのまま残している。** 事実の出どころを示す引用で、
仕様9-6 が持たせている透明性の担保だから。「公式サイト」= 購入導線 とは位置づけが違う。

## 前提: AdSense アカウントは既にある

seisan3 (`https://seisan3.com`) で **`pub-3292112504579579`** を使用中
(スクリプト設置済み・広告ユニットは未設置)。したがって beer は
**新規アカウント作成ではなく、既存アカウントへのサイト追加**になる。
`ads.txt` も pub-ID が既知なので先に置ける。

**ただし審査はサイトごと。** seisan3 が通っていることは beer の承認を意味しない。

### つまずいた点 —— サイトマップの送信

1. `sitemap.php` を送ると「サイトのサイトマップへの有効なパスを入力してください。」で弾かれる。
   **Search Console は拡張子で判定している**らしく、中身が XML でも `.php` は通らない
2. `/sitemap.xml` から `sitemap.php` へ振り向けた(Apache は `AllowOverride None` で
   `.htaccess` が使えないため **nginx の `location = /sitemap.xml`** で対応)
3. それでも弾かれた。原因は **ドメインプロパティは完全なURLを求める**こと。
   `sitemap.xml` ではなく **`https://drtbeer.com/sitemap.xml`** と入れて送信できた
   (URLプレフィックス型なら続きだけでよい。プロパティの型で入力形式が違う)
